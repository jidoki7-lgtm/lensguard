# LensGuard

영상 속 사람이 스마트(AI) 안경이나 초소형 카메라를 착용했는지 Claude 비전 AI로 분석하는 앱 프로토타입.

## 구조
- `app.py` — Flask 서버. `/api/analyze`가 프레임(JPEG base64)을 받아 Claude로 분석해 JSON 반환
- `static/index.html` — 영상 촬영/선택 → 프레임 8장 추출 → 서버 분석 → 결과 박스 오버레이

## 실행
```bash
pip install flask          # 이미 있으면 생략
export ANTHROPIC_API_KEY=sk-ant-...   # 없으면 MOCK(데모) 모드
python3 app.py             # http://localhost:8000
```
폰에서 테스트하려면 같은 Wi-Fi에서 `http://<PC-IP>:8000` 접속 (촬영 버튼은 폰 카메라를 호출).
카메라 직접 접근이 필요한 기능은 HTTPS가 필요하니 배포 시 유의하세요.

## 한계 (중요)
- 한 프레임의 시각 정보만 보므로 초소형 카메라는 거의 못 찾고, 스마트 안경도 오탐/미탐이 있음
- 결과는 "의심 후보"일 뿐 확정이 아님. 여러 프레임에서 반복될수록 신뢰도가 높음
- 정확도를 올리려면: 스마트 안경 이미지 데이터셋으로 YOLO 등 탐지 모델 학습 → 1차 탐지, Claude로 2차 확인(하이브리드)
- 보강 아이디어: 근적외선/렌즈 반사광(역반사) 탐지, 전자파/적외선 센서 연동

## 프라이버시
프레임은 메모리에서만 처리되고 저장되지 않습니다. 프롬프트도 신원 식별을 하지 않도록 제한되어 있습니다.
